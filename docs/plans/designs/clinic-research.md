# 한의원 홈페이지 리서치 브리프 (oma-search + oma-market)

> 2026-06-16 · 실제 웹 조사 기반. 기존 "별채/사상체질 퀴즈/모던 웰니스" 컨셉이 현실 한의원과 동떨어졌다는 피드백을 받고 재조사.

## 1. 실제 한의원 홈페이지 핵심 구성 (근거)

자생한방병원 GNB 실측: **척추·관절 → 클리닉(질환별) → 치료법 → 한약 → 커뮤니티 → 예약·문의 → 병원소개**.
일반 한의원 공통 필수 요소:

| 요소 | 내용 |
|---|---|
| 진료안내 | 질환·증상별 진료 (주력 분야 명확히), 치료법(추나·침·약침·한약) |
| 의료진 소개 | 원장 전문분야·약력 — 신뢰의 핵심 |
| 보험 안내 | 건강보험(추나) · 자동차보험(교통사고) · 실손 — 비용 불안 해소 |
| 비급여 진료비 | 추나·약침·한약 가격 투명 공개 (환자가 비교함) |
| 예약·상담 | 전화·카카오·온라인, **야간진료/주말** 강조 (직장인 접근성) |
| 오시는 길 | 주소·교통·주차 |

## 2. 환자가 한의원 고를 때 보는 것 (근거)

1. **진료 방향·의료진 구성** (상담 중심인지 시술 중심인지)
2. **후기 키워드** — 추나요법 / 통증 / 교통사고 후유증 / 야간진료 반복 여부
3. **비급여 진료비** — 추나·약침·한약 가격 비교 (모두닥 등)
4. **방문 목적·동선** — 반복 방문 가능성, 집·직장 거리

## 3. 실제 수요가 큰 진료 (근거)

- **척추·관절 통증 + 추나요법** — 2019년 건강보험 급여화(연 20회, 본인부담 1~3만원). 환자 유입 1순위.
- **교통사고 후유증** — 자동차보험 적용 한방치료. 큰 트래픽 드라이버.
- **한방 다이어트** — 다이어트 한약(자비), 1:1 관리, 비대면+택배까지 확장.
- **통증·만성질환 한약 처방** — 침·약침·한약 종합. 보약/피로/체질개선.
- (부가) 비염·소아성장·부인과(갱년기·생리)·탈모.

## 4. 의료광고법 가드레일 (중요 — 근거)

- **환자 치료경험담/후기를 홈페이지에 게시 = 불법 의료광고 소지.** → 가짜·자작 후기 절대 금지. 후기 섹션 대신 안전한 신뢰요소 사용.
- 안전한 신뢰요소: 의료진 약력, 진료 프로세스 설명, 보험 적용 안내, 비급여 가격 투명 공개, 인증·협력(자동차보험/산재지정 등), 연구.
- "최고·1위·유일·100%·효과 보장" 금지. 의료광고 심의번호 표기.

## 5. 재구성 결론 (이 사이트에 반영)

기존 비주얼(웜 아이보리+딥그린, 명조 헤드라인, 라운드 카드, 모션, 분위기 밴드)은 유지 — 사람이 만든 톤으로 평가됨.
**콘텐츠/IA를 현실 한의원으로 전면 교체:**

1. 히어로 — 증상·질환 중심 카피 + 전화예약/진료안내 CTA (퀴즈 CTA 제거)
2. 빠른 안내 스트립 — 건강보험·자동차보험·실손 적용 + 야간진료 + 주차
3. 진료안내 — 척추·관절(추나) / 교통사고 후유증 / 한방 다이어트 / 한약·보약 4영역 카드
4. 보험 안내 밴드 — 건보 추나 / 자보 교통사고 / 실손
5. 치료법 — 추나·침·약침·뜸·한약
6. 원장 소개 — 통증·추나·한약 중심으로 재서술
7. 진료비·진료시간 — 비급여 가격표 + 야간/토 진료 + 예약 방법
8. 오시는 길 / FAQ(보험·추나횟수·교통사고절차·한약) / 예약 폼
9. **사상체질 1분 퀴즈 = 메인에서 제거** (니치 기믹, 현실 한의원 미사용)
